                                                              2. Tahapan pengerjaan: Unduh berkas latihan Svelte pada repositori berikut: Github

                                                                a. Modul Helper & Custom Hooks:

                                                                • src/helpers/apiHelper.js: Pembungkus fetch ke REST API, header Authorization: Bearer <token>, serta getAccessToken dan putAccessToken di localStorage.

                                                                • src/helpers/toolsHelper.js: Dialog SweetAlert2 (showSuccessDialog, showErrorDialog, showWarningDialog, showConfirmDialog) dan pemformatan tanggal.

                                                                • src/hooks/useInput.js: Hook input formulir.

                                                                b. Modul Fitur:

                                                                • src/features/auth/: Login (POST /auth/login), register (POST /auth/register), dan logout. State ada di Svelte store authStore.js. Halaman LoginPage.svelte dan RegisterPage.svelte dibungkus AuthLayout.svelte.

                                                                • src/features/todos/: CRUD tugas, filter selesai, unggah cover, serta komponen navbar, sidebar, editor markdown, dan modal tambah, ubah, serta ubah cover. Layout dashboard adalah TodoLayout.svelte. Halaman daftar ada di HomePage.svelte, detail di DetailPage.svelte pada rute /todos/:todoId.

                                                                • src/features/users/: Daftar pengguna (/users) dan profil (/profile), termasuk ubah data, foto, dan kata sandi.

                                                                • src/features/common/: Halaman 404 NotFoundPage.svelte.

                                                                c. State:

                                                                • Gunakan Svelte store (writable / derived), bukan Pinia. Store dipasang langsung di komponen lewat impor, tanpa createPinia().

                                                                d. Rute (src/router.js):

                                                                • Router kustom memakai History API (navigate, currentPath, resolveRoute).

                                                                • /auth/login dan /auth/register memakai layout autentikasi.

                                                                • /, /todos/:todoId, /users, dan /profile memakai layout todo.

                                                                • Path yang tidak cocok menampilkan halaman 404.

                                                                • src/App.svelte memilih layout dan halaman dari hasil resolveRoute.

                                                                e. Pengujian:

                                                                • src/setupTests.js memuat @testing-library/jest-dom dan mock lucide-svelte.

                                                                • src/test-utils.js menyediakan renderWithProviders untuk komponen Svelte beserta store.

                                                                • Setiap helper, hook, API, store, komponen, modal, layout, halaman, router, dan App.svelte memiliki berkas uji.

                                                                • Jalankan pengujian dengan bun run test atau bun x vitest run. Jangan memakai bun test.
